Installation Command

Run this single command to install and configure your Decred node:

curl -fsSL https://node.dcr.pw | sudo bash Linux

This command will download and execute the installation script, setting up a full Decred node on your system.

Docker Compose Setup

Download or copy the docker-compose.yaml file: 

services:
  dcrd:
    image: ghcr.io/jzbz/dcrd-mainnet:latest
    container_name: dcrd
    restart: unless-stopped
    read_only: true
    stop_grace_period: 60s
    # Add the service name to the RPC TLS certificate for remote RPC clients.
    command: ["--altdnsnames", "dcrd"]
    ports:
      - "9108:9108"   # mainnet peer-to-peer
      # - "9109:9109" # mainnet JSON-RPC (uncomment to expose remotely)
    volumes:
      - decred-data:/home/decred

volumes:
  decred-data:

⬇ Download docker-compose.yaml

Then run: docker compose up -d
